# 五分钟演示脚本（P5）

面向课堂/答辩现场，目标是在 5 分钟内完整走通
「选网卡 → BPF → 抓包 → 详情 → 十六进制 → 显示过滤 → 同流 → 流时序图 → 导出」。
每一步都给出**操作**与**讲解要点**，可按现场流量灵活删减。

> 演示前必须确认已获得网络所有者授权。不要在现场抓取他人隐私流量，
> 建议使用自己的热点/回环或预先准备好的合成 PCAP。

## 0. 准备（30 秒，不计入 5 分钟）

- 已安装 Npcap 并勾选 loopback；`python -m nps --list-interfaces` 能看到设备；
- 启动 GUI：双击桌面 `NPS Sniffer`，或运行 `python -m nps`；
- 准备一个产生流量的动作：浏览器打开 `https://example.com`，或 `ping` 本机网关。

## 1. 选网卡（0:00–0:30）

**操作**：工具栏「接口」下拉框选择正在使用的 Wi-Fi/有线网卡；
回环演示则选 `\Device\NPF_Loopback`。

**讲解**：

- 列表来自 `pcap_findalldevs`，标注「回环」的是 Npcap Loopback Adapter；
- 虚拟适配器（WAN Miniport、Wi-Fi Direct）通常没有流量，演示时避开；
- 回环链路是 `DLT_NULL`（4 字节地址族），不是以太网，解析器按链路类型取偏移。

## 2. 捕获过滤器（0:30–1:00）

**操作**：在「捕获过滤器」输入 `tcp port 443`（HTTPS）或 `icmp`，点「开始」。

**讲解**：

- 这是 **BPF 内核过滤器**，不匹配的包根本不会进入用户态，和后面的显示过滤不是一回事；
- 表达式由 `pcap_compile` 编译，语法错误会直接显示 `pcap_geterr` 原文；
- 现场若不确定端口，先留空抓全量，再用显示过滤裁剪。

## 3. 抓包与列表（1:00–1:40）

**操作**：保持浏览器访问 `https://example.com`，观察列表滚动；
状态栏展示「包数 / 队列丢弃 / 内核丢弃」。

**讲解**：

- 捕获线程只做 `string_at` 拷贝入队，界面每 16 ms 批量取最多 300 条，互不阻塞；
- 协议列优先显示 DPI 结果（HTTP/TLS/DNS/SSH/BitTorrent），端口推断的结果在悬停提示里标「端口推断」；
- 「队列丢弃」与「内核丢弃」语义不同：前者是用户态消费慢，后者是驱动缓冲不足。

## 4. 详情树（1:40–2:20）

**操作**：选中一条 TLS 包，展开 `Ethernet → IPv4 → TCP → TLS`。
找到 `server_name`（SNI）字段。

**讲解**：

- 详情树按层展开，字段值来自解析器的扁平字段表；
- TLS 只读明文握手：能看到 SNI、ALPN、版本与套件，应用数据只标「N bytes（密文）」；
- 右键字段可「复制值 / 复制字段」，答辩时可直接读出域名作为证据。

## 5. 十六进制联动（2:20–2:50）

**操作**：在详情树点击 `server_name`，观察下方十六进制对应字节被高亮。

**讲解**：

- 字段节点保存帧内绝对偏移与长度，十六进制视图直接按偏移绘制高亮，不做字符串匹配；
- 高亮位置与包列表的时间/长度列互相印证，说明解析没有"猜"。

## 6. 显示过滤器（2:50–3:30）

**操作**：在第二行输入 `ip.addr == 93.184.216.34 && tcp.port == 443`，
再试 `protocol == tls`、`!(protocol == arp)`。

**讲解**：

- 显示过滤只影响显示，不改变捕获；语法支持比较、逻辑运算、CIDR 与括号；
- `protocol` 是**最高层协议**，DPI 之后 `protocol == tcp` 不再命中 TLS 流，
  要看传输层请用 `ip.proto == tcp`；
- 错误表达式只标红提示，保留上一条有效规则，列表不会闪跳。

## 7. 会话与同流高亮（3:30–4:00）

**操作**：切到右侧「会话」页签，点击一条会话；
或直接点列表中的包，观察整条流被浅蓝高亮、会话行自动选中。

**讲解**：

- 会话键是规范化五元组（端点排序），双向流量合并为同一个 `stream_id`；
- 面板给出上下行包数/字节、时长、TCP 状态与 DPI 协议；
- 双击会话跳转到该流首包；若首包已被容量上限淘汰，状态栏会明确提示。

## 8. 流时序图（4:00–4:30，P5 新增）

**操作**：切到右侧「流时序图」页签；滚轮缩放、拖动平移、双击复位。

**讲解**：

- 横轴时间、纵轴两端（上=客户端、下=服务端），箭头表示方向，线旁数字是包长；
- 密集时按像素列聚合，颜色表示主导方向；悬停可看包序号、方向、长度与相对时间；
- 10,000 包渲染约 14 ms（见 `docs/PERF.md`），缩放不重新解析包。

## 9. 导出（4:30–5:00）

**操作**：点「保存」，确认授权提示后导出 `demo.pcap`，用 Wireshark 打开对比包数。

**讲解**：

- 导出写标准 PCAP，包含原始字节与时间戳，可直接用 Wireshark 复核；
- 导出前会二次提示敏感信息与授权，演示结束建议删除文件；
- 本项目不做 TLS 解密、不做 TCP 重组，边界在 `docs/ARCHITECTURE.md` 中写明。

## 现场应急

| 现象 | 处理 |
| --- | --- |
| 设备列表为空 | 确认 Npcap 服务 `sc query npcap` 为 RUNNING；重开 GUI |
| 抓不到任何包 | 换物理网卡；虚拟适配器通常无流量；确认 BPF 没写错端口 |
| 回环抓不到 | Npcap 安装时需勾选 loopback；确认选的是 `NPF_Loopback` |
| 界面无响应 | 停止后清空再开始；检查状态栏「队列丢弃」是否持续增长 |
| 演示流量含隐私 | 立即停止、清空列表、删除导出文件，改用合成 PCAP 回放 |
